# Chronicle v0.9.3 — Quest Authority + Scan Reliability

## Quest database is authoritative
Chat is now explicitly instructed that World > Quests is the only authoritative quest tracker.

When the player asks to add/start/create/complete/fail/pause/update a quest:
- Chat should not invent or maintain a separate quest card/list/JSON block.
- Chat acknowledges the story naturally.
- Chronicle Review owns the persistent quest record.

When asked to show quests, Chat should mirror canonical quest records as a read-only view.

## Explicit quest fast path
Common explicit player quest commands no longer depend entirely on the AI continuity analyzer.

Chronicle can immediately create a Review proposal for:
- Add/create/start a quest
- Complete/finish a quest
- Fail a quest
- Pause/suspend a quest

For lifecycle changes it reuses the exact existing canonical quest title.
If only one quest is Active, phrases such as “the mission is complete” can resolve to that active quest.

The general AI analyzer still runs afterward as a safety net.

## Faster continuity scans
Automatic and manual scans now use a compact automation-specific database snapshot instead of the full storytelling context.

It still includes:
- campaign location/objective
- canonical character IDs and continuity-critical fields
- locations
- factions
- every quest and its exact title/status/objective
- recent timeline events

This substantially reduces unnecessary prompt size without removing the structured records needed for continuity detection.

## Manual scan can no longer get locked out
If an automatic scan is already running, `Scan last exchange` remains clickable.

Pressing it changes the action into a queued rescan:
- current automatic scan finishes
- Chronicle automatically rescans the latest exchange once more
- the user receives a notice that the rescan was queued

This closes the v0.9.2 behavior where the manual scan could appear unavailable while the automatic analyzer was still busy.

## Import performance
External campaign analysis remains a comprehensive AI migration pass, so large campaign imports can still take noticeably longer than normal exchange scanning.
v0.9.3 intentionally does NOT truncate imported campaign text just to make it faster, because doing so could silently lose old canon.
The normal post-message/manual scanner is the part optimized in this patch.
