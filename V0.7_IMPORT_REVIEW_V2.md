# Chronicle v0.7.0 — Import Review v2

This completes the external campaign importer review stage.

New:
- Edit extracted campaign metadata before import.
- Edit complete imported character drafts before import.
- Change cast tiers and confidence labels.
- Remove unwanted character drafts.
- Edit or remove extracted memories/lore.
- Filter review by All / Needs Review / Ambiguous.
- Summary counts for characters, memories, messages, and confidence levels.
- `Approve & Create` now commits the edited draft, not the original AI extraction.

Nothing on the Import Review screen becomes campaign canon until the user approves it.
