# Chronicle v0.4 — Review Gate

## Core rule

The AI cannot silently rewrite campaign canon.

Every automatic continuity change is first written as a pending `change_proposals` record.
Only the user can turn that proposal into real campaign data.

## Added

- Fourth bottom tab: **Review** with a notification badge
- Automatic continuity scan after AI storyteller replies
- Optional automatic scanning toggle in AI Provider settings
- Manual **Scan last exchange** button
- Proposal summaries
- Exact proposed fields shown before approval
- Reason/evidence shown for each proposal
- **Approve**
- **Reject**
- **Edit before approving**
- Approved `memory_new` proposals create campaign memories
- Approved `character_update` proposals modify the targeted stable character ID
- Approved `campaign_update` proposals update campaign details
- Rejected proposals never change canon
- Review extraction failures never interrupt the campaign chat

## Free-model note

Automatic Review scanning uses a second AI request after each storyteller reply.
With a provider that limits free requests, this effectively reduces the number of story turns available per day.
You can disable automatic scanning and use **Scan last exchange** manually whenever you want.
