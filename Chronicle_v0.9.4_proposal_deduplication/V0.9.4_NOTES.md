# Chronicle v0.9.4 — Proposal Deduplication

## Generic Review deduplication
Chronicle now treats proposals as duplicates when they have:
- the same canonical target/type
- the same canonical identity (for example the same quest title)
- the same effective proposed changes

JSON formatting and field ordering no longer make identical changes look different.

## Race-condition guard
v0.9.3 intentionally has two quest detection layers:
1. explicit local quest-command fast path
2. general AI continuity analyzer

Those can finish close together. v0.9.4 re-checks pending proposals after insertion and automatically supersedes later equivalent copies, leaving one actionable Review proposal.

The guard applies generically to structured world proposals:
- locations
- factions
- quests
- timeline events

This preserves redundant detection without redundant approvals.

## Canonical behavior
This does not change the successful v0.9.3 quest upsert behavior. Approving a quest proposal still updates/creates one canonical quest record.
