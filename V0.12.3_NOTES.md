# Chronicle v0.12.3

- Reduces lossless import segments from 16,000 to 6,000 target characters for faster local analysis.
- Retains 500 characters of overlap so facts spanning boundaries remain understandable.
- Keeps one Ollama model loaded while independently checkpointing every completed segment.
- Validates source hash, source length, and segmentation layout before resuming.
- Never reuses checkpoints made with an older or differently sized segmentation layout.
