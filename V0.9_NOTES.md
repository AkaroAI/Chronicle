# Chronicle v0.9.0 — World State & Story Timeline

## New structured world canon
Chronicle now stores four new campaign-scoped record types:
- Locations
- Factions
- Quests / story threads
- Timeline events

These records are separate from free-form Memory so future map/codex systems can use them directly.

## World tab
A new World tab browses:
- Locations with region, parent location, discovery state and status
- Factions with relationship-to-party, goals and status
- Quests with objective, related location/faction and progress state

## Timeline tab
A new Timeline tab shows approved meaningful story milestones.
Events support:
- event type
- location
- involved characters
- story arc
- importance
- chronological story order

The timeline deliberately ignores routine dialogue/minor flavor unless Review approves it as a meaningful event.

## Review integration
The continuity analyzer can now propose:
- location_upsert
- faction_upsert
- quest_upsert
- timeline_event_new

Nothing writes directly to world canon. These still pass through Review and evidence safeguards.

## Evidence attribution improvement
If the user supplies a fact and the assistant merely reformats/repeats it, the analyzer is explicitly instructed to classify it as Player Confirmed rather than Assistant Only.

World, faction, quest and timeline changes cannot be approved from Assistant Only or Unverified evidence without reclassification.

## Story context
Approved locations, factions, quests and recent timeline events are fed back to Chronicle's storyteller as structured canonical context.

## Backup
.chronicle backup format advances to v3 and now preserves all v0.9 world-state and timeline records.
v1 and v2 backups remain readable.

## Database
Room schema: 5
Migration 4 -> 5 creates the new world/timeline tables without deleting existing campaigns.
