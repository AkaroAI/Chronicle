# Chronicle v0.10.0 — World Explorer

## World Explorer map
The existing World tab now opens into a visual World Explorer with:
- Map / Locations / Factions / Quests modes
- visual location nodes generated from approved Location canon
- persistent user-controlled node positioning
- parent-location connection lines
- current party location highlighting
- discovery-state fog behavior
- location search
- Visited / Discovered / Heard About filters

## Persistent layout
Map positions are presentation state, stored per campaign on-device.
Drag a location node and Chronicle remembers its position.
The AI does not control or rearrange your layout.

## Location detail cards
Tap a map node to open a location detail sheet showing:
- region / discovery / status
- description and parent location
- related quests
- related factions
- timeline history at that location
- notes

This reuses existing canonical records rather than duplicating world data.

## Quest Explorer
World > Quests now has:
- Active
- Paused
- Completed
- Failed
- All
filters, so completed quests remain campaign history without cluttering the active view.

## Fog of war
Unknown locations are not drawn.
Heard About locations appear faded.
Discovered and Visited locations appear normally.

## AI world rules
The continuity analyzer is now explicitly map-aware:
- physical arrival => Visited
- learned about only => Heard About
- known but not visited => Discovered
- preserve parentLocation hierarchy
- actual party movement should also propose campaign currentLocation changes

## Scope
v0.10.0 is the World Explorer foundation.
Dedicated editable route records, distance/travel metadata, richer region canvases, and generated fantasy-map art are intentionally reserved for follow-up v0.10.x updates so this first visual layer stays compatible with the stable v0.9 canon pipeline.
