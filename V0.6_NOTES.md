# Chronicle v0.6.0 — Campaign Portability + Branding

## Portable .chronicle backups
Export the selected campaign from the three-dot campaign menu.

The .chronicle package is ZIP-based and contains:
- manifest.json
- campaign.json
- characters.json
- memories.json
- messages.json
- proposals.json

Format version: 1.

## Import safety
Import never silently merges.
The user chooses:
- Import as copy
- Replace current
- Cancel

## Preserved data
- campaign settings/state
- characters and cast tiers
- memories/lore
- full chat history
- proposals and proposal status

Character IDs are remapped during restore, including proposal references and the player-character reference.

## Security
AI provider credentials/API keys are not included in campaign exports.

## Branding
The new anime fantasy Chronicle artwork is the Android launcher icon.
