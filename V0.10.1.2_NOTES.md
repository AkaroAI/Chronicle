# Chronicle v0.10.1.2 — Presence & Location Identity Reliability

## Fixes in this patch

### 1. Chat is not Review
The storyteller is now explicitly forbidden from:
- asking the player to approve/confirm/reject proposals inside Chat
- pausing the story waiting for Chat approval
- claiming a proposal was approved because the player answered in Chat

Review remains a separate app UI and the automatic persistence pipeline runs independently.

### 2. Manual Scan now has parity with normal chat
`Scan last exchange` now runs the deterministic quest and character-movement fast paths before the AI continuity analyzer.
If the AI analyzer misses a movement, manual Scan can still recover it.

### 3. Location identity normalization
Location matching now normalizes:
- East ↔ Eastern
- West ↔ Western
- North ↔ Northern
- South ↔ Southern
- optional `the`
- punctuation/case/spacing

So `East Gate`, `the eastern gate`, and `Eastern Gate` resolve to the same location identity.

### 4. Missing-location recovery during movement
If a player explicitly moves a known character to a place that is missing from structured World State, Chronicle no longer silently drops the movement.
It proposes:
- the missing Location
- the Character location update

Both remain Review-gated.

### 5. More deterministic external imports
After AI import analysis, Chronicle performs a deterministic source-text location recovery pass.
It preserves obvious place references such as:
- `Current Location: Briarwatch Village`
- `rush to the eastern gate`
- `Moonspire Observatory`

Recovered locations are marked `Needs review` in Import Review instead of disappearing because one AI analysis run happened to omit them.
