# Chronicle v0.7.0 — External Campaign Importer

## New
- Import Existing Campaign for TXT, Markdown, JSON, and other readable text files.
- AI-assisted extraction into a reviewable draft.
- Confidence labels: High confidence, Needs review, Ambiguous.
- Cast-tier inference: Main, Secondary, Supporting, Background.
- Extracts campaign metadata, characters, and durable memories/lore.
- Common `User:`, `Player:`, `Assistant:`, `Chronicle:`, `GM:` and `Game Master:` transcripts are preserved as Chat rows.
- If a transcript cannot be safely segmented, the original source is preserved as an Imported Source memory instead of being discarded.

## Safety
- External analysis does not write canon immediately.
- Import Review appears first.
- Nothing is committed until `Approve & Create`.
- Analyzer is explicitly instructed not to invent missing facts or silently reconcile contradictions.
- Existing `.chronicle` backup restore remains separate and deterministic.
