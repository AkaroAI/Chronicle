# Chronicle v0.12.0 — Lossless Import

- Accepts a complete campaign document up to 20 million characters.
- Splits internally at paragraph, line, or sentence boundaries with overlapping context.
- Verifies that primary ranges cover every source character exactly once before analysis.
- Shows segment-by-segment progress, merge, continuity-check, and Import Review stages.
- Caches every completed analysis by source SHA-256; reselecting an unchanged file resumes it.
- Merges characters, locations, factions, quests, timeline events, memories, and campaign state.
- Preserves the untouched original source in ordered database chunks and campaign backups.
- Adds a Room v6→v7 migration for lossless imported-source storage.
- Repairs the clipped campaign selector and enforces readable dark-mode chat text.
