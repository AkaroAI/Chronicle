# Chronicle v0.13.0

- Adds recursive adaptive campaign-import segmentation.
- A dense or timed-out source range is divided at a safe paragraph, turn, or sentence boundary.
- Only the failed range is divided; completed ranges remain checkpointed.
- Checkpoints are keyed by exact source start/end offsets rather than ordinal segment numbers.
- Resuming recognizes completed child ranges and reconstructs the same subdivision path.
- Exact primary-range coverage is verified again after all adaptive subdivisions.
- Transport failures trigger subdivision immediately instead of repeating the identical expensive request.
