# Chronicle v0.10.1.5 — Local Chronicle Engine Connection

Chronicle can now connect to Chronicle Engine over HTTP on a trusted private LAN.

## Network safety

- Plain HTTP is accepted only for literal private or loopback IPv4 addresses.
- Public providers continue to require HTTPS.
- API keys are rejected on HTTP connections so credentials cannot be sent unencrypted.
- The provider settings screen explains the local-connection requirements.

## Build and compatibility

- Application ID remains `com.akaroai.chronicle`.
- Database and backup formats are unchanged.
- Existing campaigns and provider settings remain intact during an in-place update signed with
  Chronicle's cached debug signing key.
