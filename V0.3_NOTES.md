# Chronicle v0.3

Adds campaign rename/edit, archive/restore, permanent delete confirmations, full editable character sheets, richer campaign context, and the database foundation for v0.4's approval-only automatic memory system.

## v0.4 review queue design
Automatic AI changes will first become `change_proposals`. The future Notifications/Review tab will show a summary, target, exact proposed changes, reason/evidence, and Approve / Reject / Edit-then-Approve controls. Nothing becomes canon until approved.

## Update signing
The workflow now caches Chronicle's debug keystore. The first v0.3 install may still require uninstalling an older build because earlier GitHub runs used ephemeral debug signing. After this build, future cached-key builds should normally update in place.
