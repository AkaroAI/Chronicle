# Chronicle v0.8.1 — Canonical Character Authority

## The problem fixed
Chat-generated character sheets were able to act like a parallel, unofficial character system.
Chronicle now treats the Character database as the single source of truth.

## Canonical character creation
When a user asks the AI to create/register a character sheet:
- the storyteller is instructed NOT to print/maintain a second authoritative sheet in Chat
- the continuity analyzer creates a `character_new` Review proposal
- Review shows the proposed complete character record
- approving the proposal creates the real Character-tab record
- Main characters default to Strict integrity; others default Balanced

Manual Add Character remains available.

## Read-only character display
If the user asks the storyteller to show an existing sheet:
- it mirrors only the canonical database record provided in context
- blank fields must remain unknown/blank rather than being invented
- Chat output is explicitly a read-only view, not an independent record

## Duplicate prevention
Before accepting a `character_new` proposal, Chronicle checks:
- existing canonical character names
- pending new-character proposals

Matching names are not duplicated.
Approval also re-checks the database to prevent race/duplicate creation.

## Source-aware proposals
The analyzer now proposes:
- evidenceType: Player Confirmed / Story Event / Assistant Only / Unverified
- changeMode: Append / Replace / Clear

This reduces manual classification and makes the v0.8 Integrity Guard useful automatically.

## Assistant-origin safeguards
A new character based only on Assistant Only or Unverified evidence is guarded.
It cannot become canon until Review reclassifies the evidence to Player Confirmed or Story Event.

Existing v0.8 rules still block Assistant Only identity rewrites.

## Smarter update behavior
The analyzer is instructed to prefer Append for evolving character information:
- personality development
- relationships
- goals
- fears
- injuries
- notes
- affiliations
- additive abilities/equipment

Replace is reserved for corrections, explicit rewrites, or genuine transformations.
