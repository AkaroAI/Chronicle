# Chronicle v0.9.1 — World Pipeline Completion

## Automatic world/continuity scanning
When real AI is enabled, every completed assistant reply now automatically runs Chronicle's continuity/world analyzer.
The manual `Scan last exchange` button remains as a fallback/re-scan tool.

This closes the v0.9 bug where World/Timeline proposals only appeared after manually pressing Scan.

## External imports understand v0.9
External campaign analysis now extracts, reviews, and imports:
- Locations
- Factions
- Quests / Story Threads
- Timeline Events

The Import Review summary counts these new records.

## Editable world import review
Before approving an external campaign, you can:
- edit/remove imported Locations
- edit/remove imported Factions
- edit/remove imported Quests
- edit/remove imported Timeline Events

These remain outside canon until `Approve & Create`.

## Dedupe
Automatic scanning now suppresses exact duplicate pending world proposals.
If a newer proposal targets the same named location/faction/quest with changed data, it supersedes the older pending proposal instead of stacking duplicates.

## Evidence
The v0.9 evidence rule remains:
facts supplied by the user and merely reformatted/repeated by the assistant should be `Player Confirmed`, not `Assistant Only`.
