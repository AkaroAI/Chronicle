# Chronicle v0.5.1 permanent release signing

Before committing these files, create these GitHub Actions repository secrets:

- CHRONICLE_KEYSTORE_B64
- CHRONICLE_KEYSTORE_PASSWORD
- CHRONICLE_KEY_ALIAS
- CHRONICLE_KEY_PASSWORD

Use the values in the separate private signing package.

This changes Chronicle from disposable debug signing to a permanent release key.

IMPORTANT:
The first APK built with this release key requires one final uninstall/reinstall because all prior installed builds were signed differently.

After that, DO NOT lose the JKS or passwords. Future Chronicle releases must use the same key.
