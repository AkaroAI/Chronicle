# Chronicle v0.11.0 — Living Chronicle

## Interface

- Adds Chronicle's midnight dark theme and dimensional surface palette.
- Replaces the six-item bottom bar with a compact seven-destination floating rail.
- Adds a dedicated Quests destination and renames Memory to Lore & Memory.
- Replaces campaign chips with a compact campaign selector while retaining create, import,
  export, edit, archive, restore, and delete controls.
- Adds names-only character browsing and a tabbed living character book.
- Adds searchable, categorized Lore & Memory browsing with honest empty states.
- Adds the routed chat composer: mode, actor, intent, and target.

## Chronicle Spirits

- Replaces generic snackbars with expressive Chronicle Spirit feedback.
- Uses distinct moods for errors, offline failures, warnings/review gates, and success.
- Keeps the full actionable message and optional details action accessible.

## Story and canon behavior

- Adds a genuinely non-canonical DM conversation channel.
- Excludes DM conversation from story history, engine payloads, and manual proposal scans.
- Story turns carry explicit actor, intent, and target routing.
- Adds deterministic paired-character interaction handling so one exchange can create all
  missing character sheets and update each already-established participant.
- Missing character sheets contain only player-established names and blank optional fields.
- Keeps canon-changing story turns behind Review before dependent narration continues.

## Compatibility

- No destructive database migration is introduced.
- Existing campaigns, messages, memories, characters, locations, factions, quests, timeline
  events, provider settings, and backups remain compatible.
