# Chronicle v0.12.1 — Word Import Repair

- Extracts actual UTF-8 campaign text from Word DOCX packages before segmentation.
- Prevents ZIP/XML package bytes from being sent to Chronicle Engine as transcript text.
- Clearly rejects PDF and legacy binary documents until dedicated extraction is available.
- Extends only long-running import analysis requests to a ten-minute read timeout.
- Adds Word-package and Unicode plain-text regression tests.
